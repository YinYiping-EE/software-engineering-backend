## 公开文件保护

前后端 `.gitignore` 增加数据库、SQLite 附属文件和常见私钥格式的排除规则。公开内容不包括 node_modules、dist、.local、实际 .env、数据库、SSH 凭据或会话密钥；保留 `.env.example` 的占位配置和测试用的固定假密钥。

提交前按 Git 实际候选文件检查路径与常见凭据格式。检查不读取或输出实际本机密钥。公开提交使用 GitHub noreply 作者邮箱，避免把本机配置的私人邮件地址加入提交。

第三方素材署名和许可说明随源码保留。静态项目展示只包含用户已授权整合的页面与资源，不包含其原工程的设备控制程序或 API 凭据。

本轮源码变更主要是公开文件保护与文档同步，未修改计算和数据库业务逻辑。服务器继续运行此前已验证的版本；上传 GitHub 不自动替换线上应用。

## 使用边界

签名浏览器身份不是账号登录。IP 归属地和 User-Agent 是估算标签，不用于认证；Cookie 清除或到期后，新身份不能恢复之前的记录。普通 Number 计算不提供任意精度保证。保护机制及这些限制均在 README 和博客中说明。
